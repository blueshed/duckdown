# Not found

There is nothing at that address. Try the [front page](/), search from the
top of any page, or read the [[/sitemap|site map]].

This page is `pages/404.md`. When a page is missing, the served site answers
with it and a 404 status, and `bun run export` writes it as `404.html`, which
is the file a static host serves for a miss. It stays out of the navigation,
the search index and the sitemap. Delete it and a miss is a plain line.
