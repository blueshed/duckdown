# Blog

This index doesn't list anything by hand. `{{pages}}` does it: newest first by
each post's `date:`, with its `description:` underneath. Write a post, save it,
and it appears here.

`feed: true` above gives the blog a feed, `/blog/feed.xml`, for
anyone who follows it in a feed reader: every dated post, newest first.
