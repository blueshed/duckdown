# Using the editor

On the left, where you are: the site's folders and pages. In the middle, what
you're changing. On the right, the page as a reader will see it.

## Keys

| Keys | Does |
|------|------|
| **⌘⏎** | Save |
| **⌘Z** / **⇧⌘Z** | Undo / redo, in a collection |
| **Escape** | Close a drawer |
| **Tab** | Move between buttons; **Enter** presses one |

## Finding your way

- **`..`** at the top of the list goes up a folder; the line at the top of
  the screen (`duckie › news › …`) goes anywhere above.
- **Resources** holds the pictures, the stylesheets and the templates.
- **Resources → icon** sets the site's icon: the picture on a browser tab and
  on a phone's home screen. Choose any picture; a square one is best. If a
  template names an icon of its own, the tab says which: that one wins.
- **Editors** is who can sign in: add someone, change a password.

## When something goes wrong

- **The clock** in a file's header shows its earlier versions. Pick one to
  see it; **Restore** puts it back.
- **Deleted**, at the top of a list, brings back a file you removed.
- A red line at the bottom says what failed. Close it once you've read it.

Nothing you save is lost: earlier versions are kept for every file.
